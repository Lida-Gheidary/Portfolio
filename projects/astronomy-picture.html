01Overview

Status: COMPLETE / DEPLOYED

PURPOSE: Analytics work often depends on pulling data out of systems that belong to someone else. This project is practice for that: working with a public API in JavaScript, sending requests, handling the response, and dealing with what comes back when it is not what you expected.

THE EXERCISE: Pick any date since 16 June 1995 and the page returns NASA's Astronomy Picture of the Day for that date, together with the explanation NASA published with it. Today's picture loads on arrival.

TECHNOLOGY: Plain HTML, CSS and JavaScript, with no framework and no build step. Hosted on GitHub Pages.

DATA: NASA's Astronomy Picture of the Day archive, read through the public WordPress REST API at science.nasa.gov. No API key is needed.

02What It Does

Status: COMPLETE

THE REQUEST: A fetch inside an async function, awaiting both the response and its JSON. The HTTP status is checked before the body is read, so a server error is caught rather than parsed.

PAGING: The loop requests up to five pages of results and stops when the matching post is found.

ERROR HANDLING: A try, catch and finally around the fetch. A failed request produces a clear message on the page instead of a console error, and the button is re-enabled either way.

LOADING STATE: The button disables itself and reads "Fetching" while a request is running.

RESHAPING THE RESPONSE: NASA returns a WordPress post. The date is read out of the post title with a regular expression, and the explanation is cut out of the HTML body and stripped of navigation and credits.

DISPLAY: Image days render as an image and video days in an embedded player. Clicking the image opens it full size, with keyboard support.

03How It Was Built

Status: AI-ASSISTED / REBUILT AFTER API MIGRATION

APPROACH: Written with AI assistance and developed in rounds, with each version run in the browser and revised against what it did.

MODELS: Built in November 2025 with Claude Sonnet 4.5, and rewritten later with Claude Opus 5.

THE REBUILD: The first version used NASA's old APOD endpoint, which took a date and returned one object. That endpoint goes offline on 1 December 2026, so the project was rewritten against its replacement, a general content API with no date lookup. Getting the same result now takes a title search, a paging loop and text extraction.
