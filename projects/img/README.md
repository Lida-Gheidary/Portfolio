# Project screenshots

Every screenshot placeholder already points to a PNG file in this folder (`projects/img/`).
Save your screenshot with the exact filename from the tables below, then commit and push it.
The image appears in its existing place after the normal GitHub Pages deployment; no HTML, CSS, or JavaScript edits are needed.

Use filenames exactly as listed, including capitalization and the `.png` extension: the live site is case-sensitive.
Export the image as PNG rather than just renaming a different file type.
Images keep their original proportions and resize to fit the page. Descriptions remain available in the enlarged viewer.
By default, loaded screenshots show a "Click to enlarge" link below the image, with the caption text hidden. The enlarged viewer includes an actual-size option and a link to the original image.
To keep a screenshot at its page size, add `data-enlarge="false"` to its `<figure>` element.
Until a file is available and loads successfully, visitors see the existing placeholder.

Example: add `projects/img/content-analytics-gtm-workspace.png` for the GTM workspace screenshot on the content analytics case study page.
