# Project screenshots

Every screenshot placeholder already points to a PNG file in this folder (`projects/img/`).
Save your screenshot with the exact filename from the tables below, then commit and push it.
The image appears in its existing place after the normal GitHub Pages deployment; no HTML, CSS, or JavaScript edits are needed.

Use lowercase filenames exactly as listed, including the `.png` extension: the live site is case-sensitive.
Export the image as PNG rather than just renaming a different file type.
Images keep their original proportions and resize to fit the page. Captions remain in place.
Until a file is available and loads successfully, visitors see the existing placeholder.

Example: add `projects/img/lidas-lens-gtm-workspace.png` for the GTM workspace screenshot on the Lida's Lens page.
